Fetching and classifying postings.

Duplicate filter (enabled by default): Every job posting is counted as its own post. This filter only removes rows that carry the exact same Job ID more than once — a scraping artifact, not a real second posting. In the current datasets every Job ID is unique, so no postings are removed and the filter has no effect on the numbers.
Unclear-category filter (on by default): Hides postings whose employer category could not be confidently determined — rows where the classifier's Employer_Category_Confidence_Level is Low, or the category is empty or marked unclear. Turn it on for a stricter view of employer demand.
Unclassified-occupation filter (on by default): Hides postings that carry no ISCO-08 occupation — rows whose ISCO_4_name is "Unclassified". These are typically non-clinical or off-sector jobs the occupation classifier declined to code. Turn it off to inspect them.
